# DzDelivery — مشروع Flutter لأندرويد

واجهة أولية عربية RTL لتطبيق توصيل بطابع بنفسجي وأبيض، مع:
- الصفحة الرئيسية والبحث والتصنيفات.
- قائمة وجبات ومحلات تجريبية.
- سلة مع تعديل الكمية وحساب المجموع بالدينار الجزائري.
- نموذج إتمام طلب تجريبي.
- صفحة طلباتي.
- لوحة تجريبية للمحل لتغيير حالة الطلب.

## مهم قبل الاستعمال الحقيقي
هذا الإصدار **نموذج واجهة يعمل محليًا**. الطلبات والمنتجات محفوظة في ذاكرة التطبيق فقط؛ لا توجد قاعدة بيانات أو حسابات مستخدمين أو مزامنة بين هاتف الزبون وهاتف التاجر. لوحة المحل الحالية للتجربة على نفس تشغيل التطبيق، وليست لوحة تجارية متعددة المستخدمين. لتشغيل خدمة حقيقية نحتاج لاحقًا إلى Backend وقاعدة بيانات وتسجيل دخول وصلاحيات وإشعارات.

## بناء APK بواسطة GitHub Actions فقط
1. أنشئ مستودعًا جديدًا على GitHub باسم `DzDelivery`.
2. ارفع كل محتويات هذا المجلد إلى جذر المستودع، مع الاحتفاظ بمجلد `.github/workflows`.
3. افتح تبويب **Actions** في المستودع، ووافق على تفعيل workflows إذا طلب GitHub ذلك.
4. اختر **Build DzDelivery APK** ثم **Run workflow**، أو ادفع commit جديدًا إلى `main`.
5. افتح نتيجة التشغيل التي اكتملت بنجاح.
6. في أسفل صفحة التشغيل، ضمن **Artifacts**، نزّل `DzDelivery-APK`.
7. فك ضغط الملف المنزّل؛ ستجد `app-release.apk`. انقله إلى هاتف Android وافتحه للتثبيت. قد تحتاج إلى السماح بالتثبيت من هذا المصدر.

## لا تحتاج إلى Android Studio
الـ workflow ينشئ ملفات Android الأساسية تلقائيًا إذا لم تكن موجودة، ثم ينفذ `flutter pub get` و`flutter analyze` و`flutter build apk --release`.
